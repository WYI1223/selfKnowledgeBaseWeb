## Architectural consistency (sets pattern for E2/E3)

### per-block isolated session ✓
- Jupyter.tsx:108 sessionId = `jupyter-${cryptoRandomId()}` (UUID per
  NodeView mount); kernel-bridge.ts:129 passes through to
  `adapter.startSession(sessionId)` unmodified.
- kernel-bridge.test.ts:399-413 explicitly witnesses this pattern.

### AbortSignal cleanup ✓
- Jupyter.tsx:104-121 useEffect creates new AbortController per mount;
  cleanup function calls `controller.abort()`.
- kernel-bridge.ts:114 registers dispose listener with `{ once: true }` —
  shutdown fired exactly once.
- kernel-bridge.ts:130-134 mid-startSession abort discards freshly-built
  session via fire-and-forget `s.shutdown().catch(() => {})`.
- kernel-bridge.test.ts:194-213 + 290-346 cover both mid-start and
  mid-stream abort paths.

### KernelError subclass triage per F R2 ✓
- kernel-bridge.ts:117 extracts `err.kind` from abstract KernelError base
  (subclasses set their own discriminant via `readonly kind = '...' as const`);
  the bridge's `kernelError` phase carries `{kind, message}` without
  importing concrete subclasses.
- kernel-pyodide errors.ts emits KernelImportError with `kind: 'import'`;
  kernel-adapter errors.ts emits startup/shutdown/interrupt/timeout with
  matching discriminants. Bridge faithfully relays each.
- Distinct branches at the consumer boundary: startup goes through
  `reportKernelError` (kernel-bridge.ts:137-139); execute() throw at
  kernel-bridge.ts:154-156; AsyncIterable throw at kernel-bridge.ts:172-174;
  interrupt throw at kernel-bridge.ts:188-190.

### KernelEvent 6-variant handling ✓
All 6 variants reachable:
- status: kernel-bridge.ts:162 continue (drives phase outside loop)
- stdout / stderr: outputReducer Jupyter.tsx:39-46 + bridge passthrough
- display_data / execute_result: outputReducer Jupyter.tsx:48-61 (formatMime
  text/plain projection — Wave 3 image/png escalation noted as future work
  in CONTRACT.md)
- error: outputReducer Jupyter.tsx:62-71 + bridge captures ename/evalue
  for execError phase (kernel-bridge.ts:167-169 + 177-178)
