### Documentation drift (informational, not blocking)

- **Plan §1043 vs implementation**: plan still says `{tex, displayMode}`;
  implementation + CONTRACT + brief say `{expression, display}`. Wave 2
  close ceremony (Z1) should reconcile plan text → ADR-0009 erratum.
  Not a D1 blocker because brief explicitly authorized the prop names.
- **Spec §160-162 children-bearing form**: `<Math display>\text{...}</Math>`
  has the LaTeX expression as MDX **children** (between tags), but `parseMath`
  only consumes `node.attributes` and would silently drop `children`. The
  current expression-as-prop choice (`<Math expression="..." display />`)
  matches CONTRACT.md §76 "Z0 sample-blocks" example. Reconcile in Wave 3
  mdx-bridge integration / Z0 sample-blocks PR — D1 surface stable enough
  to defer. Recommend an ADR-0009 erratum or a CONTRACT note explicitly
  rejecting children-bearing form so future `mdx-bridge` integration knows
  the routing intent.
