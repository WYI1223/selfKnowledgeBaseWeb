## Section 2 — OUT-OF-SCOPE changes mixed into working tree (BLOCKER for C2 commit)

The unstaged working tree currently contains the following changes that are **NOT** part of Task C2 scope per Wave 2 plan §Task C2 (lines 900-955) and the C2 task brief:

### 2.1 — block-foundation BlockKind 2→4 expansion (belongs to D1 / E1 bundles)

- `packages/block-foundation/src/registry.ts`: `BlockKind = 'prose' | 'component'` → `'prose' | 'component' | 'render' | 'viz'`
- `packages/block-foundation/CONTRACT.md`: kind enumeration updated to four-way + invariant rewrite
- `packages/block-foundation/RFC.md`: kind documentation expanded to four-way + table row in §Compile-time errors

**Why this is out-of-scope for C2**:
- C2 plan §Task C2 lists files as `packages/block-callout/src/ui-default/*` + `packages/block-callout/src/__tests__/ui-default.test.tsx` + `packages/design-tokens/CONTRACT.md`. block-foundation files are **not** mentioned.
- block-callout `core-definition.ts` already uses `kind: 'component'` (a Wave 1 valid kind); C2 ui-default does NOT exercise `'render'` or `'viz'` paths.
- The 4-way expansion is logically motivated by D1 (block-math = `'render'`) and E1 (block-jupyter = `'viz'`), which are still **in_progress** (see TaskList #16 D1 / #21 G1) and not yet committed.
- This is exactly the failure pattern ADR-0007 D2 row 1 (CONTRACT-level change) wants pr-gate + pr-reviewer to gate independently — bundling it under C2 obscures the review trail and would force re-review when D1 / E1 land.

**Required action**: git-operator must NOT stage these three files in the C2 commit. They should be split into a separate D1 / E1 prerequisite bundle (e.g., `feat(block-foundation): BlockKind 2→4 additive expansion`) with its own ADR-0007 D2 row 1 review chain.

- `tsconfig.json`: `+ { "path": "./packages/block-math" }` + `+ { "path": "./packages/editor-toolbar" }`

These paths point at **untracked** package directories (`packages/block-math/` + `packages/editor-toolbar/` per `git status`). The C2 bundle adds neither dependency, so adding the references here mid-C2 is a cross-track contamination.

**Required action**: git-operator must NOT stage `tsconfig.json` in the C2 commit. The two new path entries belong to their respective package bundles (D1 for block-math, G1 for editor-toolbar) where the package dirs themselves get committed.
