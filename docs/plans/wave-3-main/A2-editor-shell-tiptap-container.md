> **Wave 3 main pipeline third PR (second of Stage A).** Populates the empty
> `@skb/editor-shell` skeleton from A1 (just merged `27a8fd1`) with a functional
> `EditorShell` React component built on Tiptap's `useEditor` + `EditorContent`

> NO kernel-* registration (A4), NO mdx-bridge save/load (A5). A2 is the

> in `happy-dom`, prove the doc shape round-trips. Closes the A1 CONTRACT.md
> "Wave 3 Stage A expansion outline" prediction for A2 verbatim — any deviation
> from that prediction at A2 is scope drift.
